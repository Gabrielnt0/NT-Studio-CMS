# Validação

Execute:

```powershell
npm run build
```

Teste na interface:

1. Exportar um backup JSON.
2. Selecionar o backup exportado e conferir a pré-visualização.
3. Cancelar sem restaurar.
4. Informar as credenciais do Supabase antigo e analisar os registros.
5. Desmarcar ao menos uma tabela.
6. Migrar as tabelas selecionadas.
7. Verificar o resultado por tabela.
